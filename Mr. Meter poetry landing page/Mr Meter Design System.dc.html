Design system · v1

Mr. Meter

A poet you talk to. The system is built to feel like a gift being wrapped, not a journal being published: warm paper, brown ink, generous air, and verse always set in a serif that reads slowly.

Rules

Verse is always serif Newsreader at 1.75 line-height, line breaks preserved. Never set a poem in the interface sans.
No emoji, ever His prompt forbids them. Line icons in currentColor, drawn at 1.35–1.7 stroke, are the only ornament.
One question at a time In copy as in conversation: one idea per screen, one button that matters, nothing racing the reader.
